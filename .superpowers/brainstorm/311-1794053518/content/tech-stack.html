Tech Stack: Wo läuft die App?

Das bestimmt wie komplex der Backend-Teil wird

A

Web-App (Browser)

React/Vite Frontend (wie das bestehende Schwammstadt-Projekt) + kleines Python/Node Backend für den Agenten. Kein App Store nötig, sofort zugänglich.

B

Mobile App (React Native / PWA)

Installierbar auf dem Handy, Kamera-Zugriff für Screenshots nativer. Aufwändiger zu bauen und zu deployen.

C

PWA (Progressive Web App)

Web-App die sich wie eine App anfühlt — installierbar, Kamera-Zugriff via Browser-API, kein App Store. Guter Mittelweg.
