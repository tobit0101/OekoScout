Agent-Architektur: Wie läuft die Queue?

Wenn ein Bürger einen Report einschickt — wie verarbeitet der Agent ihn?

A

Sofort (synchron)

Beim Absenden wird der Agent direkt aufgerufen, der Bürger wartet ~5-10 Sek. auf das Ergebnis. Einfach, kein Queue-Overhead — aber bei vielen Meldungen gleichzeitig kann es hängen.

B

Queue (asynchron)

Report landet in einer DB-Queue, ein Background-Worker holt ihn ab und verarbeitet ihn. Bürger sieht "In Bearbeitung" und kriegt später eine Benachrichtigung. Robuster, skalierbarer.

C

Hybrid: sofort + Queue für Mails

Klassifizierung passiert sofort (schnell, ~2 Sek.), aber Mail-Versand und Backlog-Eintrag laufen async im Hintergrund. Beste UX + Zuverlässigkeit.
