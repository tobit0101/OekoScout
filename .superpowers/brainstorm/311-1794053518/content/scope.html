Scope: Welcher Teil zuerst?

Die App hat drei eigenständige Subsysteme — was soll zuerst gebaut werden?

A

Report zuerst

Meldung einreichen → Agent-Queue → Mail / Backlog / Auto-Antwort → Bürger-Revision. Der Kern-Workflow mit dem meisten Mehrwert.

B

Wishes zuerst

Ideen posten, upvoten/downvoten, Zyklen + Stadt-Feedback. Simpler zu bauen, gutes Bürger-Engagement.

C

Alle drei als eine Spec

Report + Journey + Wishes in einem Zug. Komplett, aber groß — schwerer in einem Sprint umzusetzen.
